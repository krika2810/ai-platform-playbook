Generative AI is a branch of artificial intelligence wherein you input the different types of data and statistics so that it will generate a new output based on the input information that you provide with. If you take an example of setting up a transportation system for your city, you need the transportation data, metadata, everything, right? If you feed in these details to the generative AI, it will generate a new route or map for your transportation system. And if you are a cloud architect and setting up infrastructure for your applications, give in the input as configuration and other metadata to this generative AI so that it will generate a new infrastructure configuration setup for your applications to run in the cloud infrastructure.
